# Synth-1

Маленькая поисковая языковая модель, обучаемая с нуля. Sane Labs.

Младшая в линейке Synth: та же архитектура, что у [Synth-2](https://github.com/ssane-labs/synth-2),
уменьшенная вдвое, только английский язык, без инструментов общего вида — но со
встроенным веб-поиском. Своя архитектура, свой токенизатор, свой код обучения.
Ни одного заимствованного веса.

**Тезис:** неопределённость — это управляющий сигнал вычислений. Модель на каждом
токене оценивает собственную неуверенность и решает по ней четыре вещи: сколько
слоёв пройти, сколькими экспертами считать, утверждать или хеджировать, и лезть
ли в поиск. Знание о своём незнании стоит в весах, а не в системном промпте.

| | Synth-1 | Synth-2 |
|---|---|---|
| Размер | ~579M всего, ~159M активных | ~1.23B, ~330M |
| Форма | 640 × 20 слоёв, 12+1 экспертов по 1024 | 768 × 24, 12+1 по 1536 |
| Словарь | 32 768, только английский | 49 152, EN + RU |
| Контекст | 2k → 4k → 8k, растяжка до 32k | то же |
| KV-кэш на 32k | 72 МБ | 155 МБ |
| Снимок на Hub | ~4.4 ГБ | 9.3 ГБ |
| Инструменты | только поиск: `search` / `open` / `find` | вызов инструментов через JSON |
| Обучение | JAX на Kaggle TPU v5e-8, сессиями по 9 часов | то же |

Что и зачем — [PLAN.md](PLAN.md). Как устроена модель — [ARCHITECTURE.md](ARCHITECTURE.md).
Зачем она в поиске и чем это меряется — [SEARCH.md](SEARCH.md).
Что происходит прямо сейчас — [STATUS.md](STATUS.md), дневник проекта.

## Что уже работает

Претрейн закончен: 161 888 шагов, отложенный лосс после отжига и растяжки — 1.78
на длине 2048 и 1.68 на 8192. Пройдена вся цепочка SFT — чтение с основанием, поиск,
калибровка уверенности, предпочтения, личность. Модель сама ищет, открывает
страницы и отвечает сводкой со ссылками; когда ответа в источниках нет, честно
говорит «не нашла» и подсказывает, где искать иначе.

| Замер | Результат |
|---|---|
| Чтение с основанием (D1) | атрибуция 97%, честный отказ 76%, ложный 8% |
| Поиск, HotpotQA по Википедии | верно 25.0%, «в источниках нет» 47.7%, выдумка 24.2% |
| Калибровка уверенности (E → F) | AUROC 0.79–0.82, ECE 0.06–0.10 |
| Личность (G) | `who-*` 12/12, утечка персоналии — 11 ответов из 257 |
| Токенизатор | 32 768: EN 6.75 симв/токен, веб-выдача 3.21 |

Цифры не парадные, и это осознанно. 25% на HotpotQA — честный результат малой
модели на вопросах в два шага; важнее здесь не точность, а доля выдумок: у
первой версии поиска она была 60.9%, у текущей — 24.2%. Модель, которая
ошибается, но не выдумывает и умеет сказать об этом, полезнее уверенной.

**Демо-чат** (`demo/chat.py`) — веб-интерфейс или терминал: поиск идёт по
~600 тыс. статей и абзацев Википедии, под ответом — ссылки и «How I found it».
Работает на TPU, на GPU и на CPU; на Kaggle — ячейка `MODE = "chat"`.

## Порядок работ

```
0. инфраструктура   готово: код, свой токенизатор, чекпоинты на Hub
A. абляции          закрыты: отвечали на открытые вопросы Synth-2
B. претрейн         готово: 161 888 шагов, 9.3B токенов к началу отжига
C. отжиг            готово: 1.78 на 2048, 1.68 на 8192
C2. контекст        готово: растяжка до 8192; 32k — впереди
D1. основание       готово: атрибуция 97%, честный отказ 76%
D2. поиск           готово: 25% HotpotQA, выдумка 24.2%
E. калибровка       готово: AUROC 0.79–0.82, ECE 0.06–0.10
F. предпочтения     готово: ORPO, честный отказ 92%
G. личность         готово: who-* 12/12
H. инференс         впереди: свой движок под CUDA, MTP-спекуляция, int8
```

До этапа G модель не знает, кто она. Это не поза, а гигиена данных: из корпуса
вычищаются тексты, где представляется чужой ассистент.

## Запуск

Локально нужен только Python 3.12 — здесь готовятся данные и токенизатор. JAX
живёт в ноутбуке Kaggle и в зависимостях этого репозитория не значится.

```bash
py -3 -m pip install -r requirements.txt
cp .env.example .env      # и вписать HF_TOKEN
```

Проверить, что источники корпуса живы:

```bash
py -3 data/sources.py smoke
```

Собрать токенизатор. **Это первое, что нужно сделать**: словарь Synth-2 сюда не
подходит. Сбор идёт часами, но переживает обрыв связи.

```bash
py -3 tokenizer/train_tokenizer.py sample --gb 1.5
py -3 tokenizer/train_tokenizer.py train
py -3 tokenizer/train_tokenizer.py eval
```

Проверить модель, оптимизатор и чекпоинты (на CPU, нужен `jax[cpu]`, пара минут):

```bash
py -3 synth1/test_model.py && py -3 synth1/test_train.py && py -3 synth1/test_checkpoint.py && py -3 synth1/test_session.py
```

Прогон без корпуса — проверить, что железо считает и шаг компилируется:

```bash
py -3 train/pretrain.py --run smoke --fake-data --steps 30 --no-push
```

Поговорить с моделью (нужен снимок на Hub; последний по цепочке — `gv4`):

```bash
py -3 demo/chat.py --ui cli
```

сборка шага на восьми устройствах.

## Правила проекта

1. Замер без числа результатом не считается. «Стало лучше» не принимается.
2. Решение, не прошедшее абляцию, помечается как гипотеза — в том числе в
   `ARCHITECTURE.md`. Решения Synth-2 наследуются вместе с пометками.
3. Каждая сессия TPU заканчивается чекпоинтом на Hub. Сессия, из которой нельзя
   продолжить, считается потерянной.
4. До этапа G в данных нет слова «Synth».
